# ServerDesk 0.16.0 — schowek, klawiatura, pliki i sieć RDP

Osadzony RDP Windows otrzymuje strefę przeciągania plików i folderów oraz przycisk wyboru plików. Przygotowane dane trafiają do schowka; użytkownik wybiera folder w zdalnym Eksploratorze i wkleja Ctrl+V. Sprawdzamy dostępność, rozmiar poniżej 2 GiB, liczbę elementów i dowiązania przed zmianą schowka. Strefa jest wyłączona przed logowaniem, przy schowku OFF i podczas reconnect. Nie jest to bezpośredni drop na natywną powierzchnię pulpitu ani własna kolejka transferów RDP.

Profil pozwala wybrać, gdzie działają skróty Windows: lokalnie, na serwerze albo tylko w pełnym ekranie, oraz opcjonalne automatyczne ponowienie po utracie transportu. Autoreconnect ma limit 5 prób i czytelny stan Ponawianie RDP. Zachowany jest systemowy dialog certyfikatu. Nowe ustawienia zapisują się i przechodzą przez eksport/import. Opcje klawiatury i autoreconnect dotyczą Windows; Linux nadal używa zewnętrznego FreeRDP.

Zmiana rozmiaru pulpitu uwzględnia DPI okna, parzystą szerokość wymaganą przez protokół i zmianę samego skalowania. Po odzyskaniu połączenia ustawienia ekranu wysyłane są ponownie. Logowanie w drugim panelu nie przejmuje fokusu aktywnej karty. Po utracie transportu czyszczony jest poprzedni komunikat o przygotowanych plikach. Źródła drag mają poprawny efekt Move/Copy i czyszczą stan po anulowaniu/utracie capture. SFTP odrzuca drop do rozłączonej lub niewłaściwej sesji. Przenoszenie serwera aktualizuje wyłącznie jego folder, zachowując aktualne zmiany nazwy, koloru i pozostałych ustawień.

183/183 testy xUnit. UI sprawdza nowe ustawienia, zapis oraz strefę RDP przy 240/520/1100 px. Rzeczywiste próby potwierdziły tekst Unicode i duży tekst w obie strony, obraz w obie strony, plik i zagnieżdżony folder na serwerze, gest pliku do strefy, blokadę schowka OFF, oraz automatyczny powrót tego samego pulpitu po wymuszonym przerwaniu transportu na 8 s. Alt+F i Ctrl+Alt+→ potwierdził użytkownik fizyczną klawiaturą. Dostępny ekran miał 100% DPI.

Pełny wykaz scenariuszy i rozróżnienie LIVE/AUTO/USER/DO TESTU: [rdp-test-matrix.md](rdp-test-matrix.md). Mieszane DPI fizycznych monitorów, pozostałe kombinacje klawiszy, bezpośrednie pliki z RDP do komputera, długotrwała/cicha utrata sieci i część gestów D&D pozostają do wykonania. Computer Use przerwano klawiszem Escape; testów gestów nie wznawiano po przerwaniu. Raport nie oznacza tych przypadków jako zaliczonych.
