# ServerDesk 0.36.2 — kompletne ikony i spójne nazwy

Menu **Układ** pokazuje odrębne ikony jednego, dwóch, trzech i czterech paneli oraz wyrównywania rozmiarów. Uzupełnione zostały ikony w menu głównym, menu kart/folderów/terminala/SFTP/komend, paskach protokołów i akcjach narzędzi sieciowych. Własne wektory aplikacji nie zmieniają oryginalnych plików Lucide.

**Paleta akcji** (Ctrl+Shift+P) wyszukuje funkcje aplikacji i ma ikony wierszy. **Komendy** (Ctrl+Shift+K) zawierają **Ściągawkę poleceń** i własne szablony. Skróty w menu mają osobną kolumnę. **Narzędzia sieciowe** oraz nazwy dziewięciu narzędzi są zgodne między paskiem bocznym, menu, powitaniem i kartami w PL/EN. Monitoring i przycisk pulpitu RDP mają zgodne podpisy i nazwy dostępności. Edytor używa nazwy „połączenie” niezależnie od protokołu.

Przetłumaczono podpisy wyboru profilu portów, DNS, uwierzytelniania i eksportu odpowiedzi, zachowując oryginalne wartości żądań. Nazwy profili/folderów i zapisane dane użytkownika pozostają dosłowne.

Publiczna beta MIT, bez nowych zależności i migracji bazy. [Ikony i zasady rozszerzania](../icons.md), [komendy](../commands.md), [narzędzia sieciowe](../network-tools.md), [zakres weryfikacji](../reports/release-verification-0.36.2.md).
