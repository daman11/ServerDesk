# ServerDesk 0.48.0 — Public Beta

Date: 2026-10-22. License: MIT.

## Guides, tool options and official documentation

Open **Commands → Guides**. Choose Mini guides or Tool options, a platform and a query. Fourteen offline PL/EN guides explain SSH keys on Linux/Windows, network configuration ownership and IP/DNS files, Linux/Windows logs, services, Docker and disk usage. Steps show risk and copy-only examples; no step executes in a session.

Twenty-two references describe 168 common options/syntax forms: GNU ls, grep, find, journalctl, systemctl, ip, ss, ssh-keygen, ssh, nmcli, netplan, curl, tail, df, du, chmod, docker logs, Git, APT and Windows cmdlets. Search exact short flags case-sensitively. Matching built-in command details also show scoped references without changing executable previews.

Expand Official documentation and click Refresh documentation to download current readable text from 31 fixed official sources. The last successful copy and check date work offline. Downloads are explicit, bounded and cancellable; failure preserves the previous copy. Open website shows the full original. Downloaded text never updates executable templates or the reviewed guide/option tables; those ship with application releases. Publisher text is normally English and may describe a different tool version.

## Installation and compatibility

Use Windows x64 Setup or a fresh portable folder; Linux x64 DEB/TAR retain existing desktop acceptance limits. Schema 4, user command JSON v1 and dependencies are unchanged. Public documentation copies use separate SQLite settings, are included in backups and survive plugin disable; full factory reset clears the active cache after backup. Disabling Commands cancels/drains its work without interrupting SSH/SFTP.
