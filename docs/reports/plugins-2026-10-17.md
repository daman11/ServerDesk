# Pluginy — weryfikacja 2026-10-17

Zakres 0.39.0: wbudowany katalog oraz cykl życia Monitoring Linux i Komendy, przełączniki w ustawieniach PL/EN, konfiguracja w istniejącym rekordzie preferencji, bez migracji SQLite lub nowych pakietów NuGet.

Testy modelu obejmują zgodność starego JSON, domyślne włączenie, niezależne wybory, nieznane ID, niezmienność listy, porównywanie ustawień po serializacji i odmowę nieprawidłowych/duplikowanych/nieograniczonych identyfikatorów przed zapisem. UI sprawdza podgląd/Anuluj/Zapisz/restart, punkty wejścia, brak dostępu do magazynu przy wyłączonym panelu, zachowanie szablonów/ulubionych, późne zakończenie anulowanego odczytu magazynu i PL/EN Graphite/Light przy font16/680×500.

Opt-in UiSmoke ROOT HOST KEY --plugins-network korzysta wyłącznie z własnego serwera OpenSSH na 22222 i jednorazowej bazy. Sprawdza aktywny monitoring i wykrywanie, zatrzymanie wolnego exec probe przez token dodatku, zamknięcie osobnego klienta monitoringu, brak starych próbek, ten sam terminal i tożsamość połączenia, SFTP, nową sesję przy wyłączonych dodatkach oraz wznowienie na istniejącym terminalu. Nie używa prywatnych połączeń ani systemowego magazynu użytkownika.

Pełne liczniki i końcowe bramki są w [raporcie wydania](release-verification-0.39.0.md) i VERIFICATION.md dołączonym do paczek. Dowody lokalne: artifacts/reports/plugins-2026-10-17 i artifacts/reports/release-0.39.0. Testy headless/WSL nie zastępują natywnego KDE, fizycznych DPI ani wielogodzinnego używania.

[Obsługa i kontrakt](../plugins.md). Obecny zakres obejmuje pluginy wbudowane; nie stanowi publicznego SDK ani systemu ładowania zewnętrznych paczek.
