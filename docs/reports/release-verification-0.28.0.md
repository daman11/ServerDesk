# ServerDesk 0.28.0 — weryfikacja pierwotnego MVP, 2026-10-15

## Zmiana i wykryte błędy

Etap dotyczy podstawowego terminala SSH: wejścia z klawiatury, schowka, PTY i cyklu życia transportu. Rzeczywisty zdalny rejestrator bajtów odtworzył dwa błędy Windows: Escape wysyłał parę rekordów Win32 zamiast pojedynczego bajtu `1b`, a Ctrl+Shift+C bez zaznaczenia wysyłał `03` i mógł przerwać proces. Ten sam test po poprawkach przechodzi. Surowy wynik sprzed naprawy zachowano w `artifacts/mvp-0280-before.txt`.

`RemoteTerminalInput.cs` obsługuje lokalne kopiowanie i Escape w zewnętrznych strumieniach VT SSH/Serial, zachowując negocjowane tryby emulatora. `TerminalResizeQueue.cs` ogranicza resize do jednego oczekującego rozmiaru; zapis sieciowy wykonuje pracownik w tle. `SshTerminalSession.CreateAsync` przenosi synchroniczne otwieranie kanału/PTY poza UI i anuluje własne połączenie. `SessionPane` czeka na zakończenie SSH przy reconnect/close. Bez zmian zależności produkcyjnych, schematu bazy i formatu poświadczeń. [Instrukcja](../releases/release-0.28.0.md), [stan MVP](../mvp-status.md).

## Kompilacja i rzeczywiste SSH

- Release rozwiązania i UiSmoke: **0 błędów / 0 ostrzeżeń**. **451/451 testów jednostkowych Windows**, bez pominiętych. Trzy nowe testy kolejki sprawdzają 10 000 zmian podczas zablokowanego zapisu, zachowanie ostatniej siatki, odrzucenie pracy po zamknięciu i pojedyncze zgłoszenie błędu.
- Narzędzie NetworkProbe początkowo użyło starego cache restore z ostrzeżeniem konfliktu logging8/10. Po normalnym restore/build: **0 ostrzeżeń**, ponowny rzeczywisty przebieg przeszedł. Nie zmieniono wersji zależności aplikacji.
- **Windows i Ubuntu 24.04.4/WSL:** własny rzeczywisty OpenSSH z wyłączonym kluczem publicznym i włączonym hasłem. Błędne hasło jest odrzucane; poprawne otwiera exec, SFTP i terminal. Tymczasowy alias NSS ma UID zwykłego użytkownika i własny katalog domowy; test nie zmienia kont OS, PAM ani systemowej usługi SSH.
- **28 przypadków inputu na obu platformach:** Escape VT, Escape po rzeczywistej negocjacji Kitty CSI-u, Enter, Tab, Ctrl+A/B/C/D/V/W/Z, Ctrl+Shift+C bez zaznaczenia, Alt+x, cztery strzałki, PageUp/Down, F1/F5/F10/F12, Home/End/Backspace, zatwierdzony tekst UTF-8 oraz Ctrl+Shift+V z bracketed paste. Test wysyła zdarzenia Avalonia do aktywnego terminala, a zdalny Python w trybie raw rejestruje rzeczywiste bajty — bez zastępowania transportu atrapą.
- Kopiowanie zaznaczonego `CLIPBOARD_żółć` trafia do odizolowanego schowka headless. Wklejenie wielowierszowego Unicode ma poprawne znaczniki bracketed paste. Osobna regresja potwierdza blokadę zdalnego odczytu i nadpisania OSC52. Nie czytano schowka pulpitu użytkownika.
- Zdalne `stty size` odpowiada siatce emulatora przy oknach **900×600, 1600×900, 1200×760**. Windows: **68×26, 153×45, 104×36**; Linux: **66×26, 149×45, 102×36** (kolumny×wiersze). Różna szerokość metryk między platformami nie zmienia zgodności PTY z lokalnym panelem.
- **Vim i nano:** rzeczywiste uruchomienie, input Unicode, Escape/Ctrl+O/Enter/Ctrl+X, zapis i wyjście. Pliki odebrane przez SFTP mają dokładnie oczekiwaną treść UTF-8. **Top, htop3.3.0, Midnight Commander4.8.30:** rzeczywisty ekran, wyjście klawiaturą i powrót do powłoki. **Bash, zsh5.9, fish3.7.0:** interaktywny start, wykonanie komendy Unicode i czyste wyjście. Narzędzia dodatkowe pobrano i rozpakowano tylko do `.tools`; nie są dołączane do aplikacji.
- Ctrl+C przerywa własny proces pierwszoplanowy; powłoka pozostaje użyteczna. Ctrl+D kończy sesję, aplikacja rozpoznaje EOF, reconnect daje nowy działający terminal i używa zatwierdzonego klucza hosta.
- **Regresja klucz/passphrase na własnym OpenSSH:** ANSI/PTY, monitoring CPU/RAM/dyski/sieć, normalne EOF, nagłe zerwanie własnego procesu potomnego sesji, klasyfikacja błędu, zamknięcie przy nieodebranym wyjściu/backpressure, dwie niezależne sesje i reconnect, przypięcie klucza oraz odmowa zmienionego klucza.
- **Rzeczywiste UI SFTP Windows/Linux:** 1MiB w obie strony z porównaniem zawartości, niezależne filtry/sortowanie/zaznaczenie, odmowa nadpisania, cancel kolejki/transferu/pytania, retry na pierwotny cel, odzyskanie błędu, zwijanie/czyszczenie i limit historii50. NetworkProbe dodatkowo sprawdza upload/download Unicode/chmod/rename/delete, zachowanie oryginału przy cancel i sprzątanie własnych plików tymczasowych.

Logi: `artifacts/mvp-0280-ssh.txt`, `mvp-0280-linux-ssh.txt`, `mvp-0280-network.txt`, `mvp-0280-sftp.txt`, `mvp-0280-linux-sftp.txt`, `mvp-0280-security.txt`, `mvp-0280-build.txt`; pełne jednostkowe wyniki `artifacts/test-results/unit.trx`. Zrzuty programów są w `artifacts/mvp-0280-ssh` i `artifacts/mvp-0280-linux-ssh`; ekran vim obejrzano. Oba własne sshd zatrzymano po testach. Nie korzystano z prywatnego RDP, hasła ani danych serwerów użytkownika.

Linux TAR/DEB: **330 plików** zgodnych z payloadem, wersja0.28.0/amd64, prawa wykonania, root ownership DEB i launcher/desktop entry. ## Granice tego etapu

To dalszy rozwój MVP, nie ogłoszenie zakończenia wszystkich kryteriów. Syntetyczne zdarzenia inputu i zatwierdzony tekst UTF-8 nie potwierdzają fizycznych AltGr/IME/układów, gestów myszy terminala ani wszystkich wariantów Kitty/Win32. Poprawka Serial korzysta z tej samej ścieżki VT, ale nie wykonano nowego testu na fizycznym porcie. Nie testowano nowych logowań RDP, AD/Microsoft ani mieszanych monitorów. Linux oznacza Ubuntu/WSLg; Windows10, KDE/KWallet, Fedora/Debian i fizyczny X11/Wayland wymagają dalszej akceptacji. Następny etap: dłuższe sesje, większe listy/drzewa, pamięć/responsywność i utrata sieci podczas transferów. [Ograniczenia bety](../known-issues.md).
