# ServerDesk 0.32.0 — weryfikacja wydania, 2026-10-16

Zestaw obejmuje zmiany od tagu v0.31.1: wyszukiwanie historii SSH/Serial, zarządzanie zaufaniem SSH, filtrowanie/sortowanie dużych list SFTP w tle oraz przygotowanie repozytorium. Wcześniejsze zamrożone wydania pozostają bez zmian. Szczegółowy zakres funkcjonalny opisują raporty [terminala](terminal-search-2026-10-16.md), [zaufania SSH](ssh-trust-management-2026-10-16.md) i [list plików](sftp-large-file-views-2026-10-16.md).

Locked restore i Release build rozwiązania oraz świeżo rozpakowanych źródeł: bez ostrzeżeń i błędów, po 503/503 testy jednostkowe Windows, bez pominiętych. SDK przypięty w global.json, zależności aplikacji bez zmian. Eksport zawiera 521 plików źródłowych wraz z lockfile, konfiguracją repozytorium/CI, dokumentacją i manifestem SHA-256; bez lokalnych narzędzi, danych użytkownika i wygenerowanych binariów. Ostateczne źródła są porównywane z plikami śledzonymi w czystym Git przy tagu v0.32.0.

UiSmoke Windows i Ubuntu/WSL: po osiem scenariuszy restart-design, localization, security, stability, protocols, large-file-views, trusted-hosts i terminal-search. Obejmują PL/EN, motywy i rozmiary z poszczególnych raportów, wyszukiwanie SSH/Serial przy 280/520/1000 px, zaufanie SSH z ochroną przed nieaktualnym wpisem oraz widoki po 50 000 metadanych na panel. Sprawdzono granice kontrolek i obejrzano reprezentatywny zrzut wąskiego terminala. Te testy widoków nie oznaczają odczytu 50 000 plików z serwera. Rzeczywiste fixture SSH/SFTP i ich ograniczenia dokumentują powiązane raporty funkcji z tego samego dnia; nie są ponownym testem prywatnych serwerów w tym przebiegu.

Gotowy EXE Windows 0.32.0.0 ma manifest Windows 10/11, asInvoker i uiAccess=false. AppProbe uruchamia kontrolę w samym EXE: utworzenie hosta RDP, zachowanie HWND przy split/floating/redock/resize i zwolnienie po zamknięciu. Bez logowania do serwera RDP. Trzy natywne starty potwierdzają widoczne granice okna po zapisaniu położenia poza ekranem, maksymalizacji i odłączonym monitorze. Test rzeczywistego restartu przez przycisk harnessu potwierdza oczekiwanie na zakończenie poprzednika, odczyt English oraz zachowanie profilu ze znakami Unicode. Nie jest to fizyczny gest użytkownika. Linux tworzy nowe okno IsViewable pod WSLg w izolowanym katalogu danych.

Skompilowany Setup przechodzi natywny odczyt napisów powitalnych: polskie znaki i separatory są poprawne. Izolowany test /NOREGISTER obejmuje instalację w ścieżce ze spacjami/polskimi znakami, start i zamknięcie, odmowę upgrade/uninstall podczas pracy bez zabijania procesu, ponowną instalację, zgodność wszystkich bajtów payloadu i usunięcie wyłącznie własnych plików. Baza, ustawienia, logi i obce pliki są zachowane. Domyślna rejestracja Apps/Start menu nie jest powtarzana, ponieważ istniejąca instalacja użytkownika pozostaje zachowana.

Paczki binarne zawierają pełne drzewo dokumentacji offline; kontrola wykrywa brakujące lub nieaktualne kopie. Windows ZIP jest porównywany z payloadem. Linux TAR.GZ i DEB zawierają 410 identycznych plików payloadu; sprawdzane są wersja 0.32.0, amd64, właściciel root, prawa wykonywania, launcher i wpis menu bez instalowania DEB w systemie. Po zapisaniu commita wydania payloady są przebudowywane; metadane ProductVersion EXE muszą zawierać SHA tego commita. Powtórzone kontrole gotowych paczek blokują zamrożenie przy błędzie.

Kontrola check-release-state odrzuca brak tagu/paczek, niezatwierdzony kod, kod wyprzedzający tag, różnice archiwum źródeł, uszkodzony plik, powtórzoną sumę, dodatkowy plik i błędną wersję metadanych. Dodatnie i ujemne przypadki sprawdzono w osobnym repozytorium fixture. Końcowa bramka wymaga czystego źródła przy anotowanym tagu, dziesięciu plików wydania, poprawnych sum i zgodnych źródeł. Zapisano i porównano SHA-256 wszystkich 130 plików trzynastu wcześniejszych wydań; pozostały niezmienione.

Advisory NuGet 2026-10-16: cztery projekty rozwiązania, źródło api.nuget.org, brak zgłoszonych podatności i problemów źródła. Sprawdzenie repozytorium, lokalne actionlint i skan sekretów przechodzą. To nie jest pełny audyt bezpieczeństwa ani wykonanie CI na GitHub. Brak skonfigurowanego remote; commit, tag i zestaw wydania są lokalne. Dowody: artifacts/reports/release-0.32.0/.

Publiczna beta MIT, bez nowych zależności aplikacji i migracji danych. Nie wykonano w tym wydaniu nowych testów fizycznego Serial, mieszanego DPI, klawiatur/IME, logowania AD/Microsoft RDP ani wielogodzinnej pracy. Linux pozostaje sprawdzony pod Ubuntu/WSLg, a RDP korzysta tam z zewnętrznego FreeRDP. Wyszukiwanie ma opisane limity bufora/zapytania/podświetleń i grafemów. Brak podpisu zaufanego wydawcy oraz automatycznej aktualizacji. [Pełne ograniczenia](../known-issues.md).
