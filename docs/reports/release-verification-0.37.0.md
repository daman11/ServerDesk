# ServerDesk 0.37.0 — zakres weryfikacji, 2026-10-16

Zakres: trzy poprawki przeglądarki połączeń (zaznaczenie folderu, ukryty profil i Enter przed przebudową, tymczasowe rozwinięcie wyszukiwania) oraz włączenie wcześniej celowanie sprawdzonych kopii SQLite i stabilizacji SFTP do lokalnego wydania.

Nowy scenariusz `--connection-browser` obejmuje PL/EN, sort/reload, wyszukiwanie/protokół/Ulubione, natychmiastowy Enter bez tworzenia sesji, zapis/odtworzenie zwiniętych folderów oraz 900 px z czcionką 16 w Graphite/Light. CI rozszerzono o ten scenariusz, istniejące `--sorting` i `--database-backups`. Macierz lokalna obejmuje Windows i Linux/WSL; nie jest to wynik zdalnego GitHub Actions.

Przed commitem wydania: 668/668 testów jednostkowych na Windows i 668/668 na Linux, 19/19 scenariuszy CI UI oraz 2/2 dodatkowe scenariusze na każdym systemie. Siedem scenariuszy rzeczywistego OpenSSH/SFTP na każdym systemie: błędy transferów, odzyskiwanie przeglądarki, przerwania i `.part`, kolejka, resilience, dowiązania i nawigacja. Audyt NuGet dla czterech projektów z zależnościami przechodnimi nie wykazał advisory ani błędów źródła. Kandydackie EXE i paczka Linux przeszły natywny start; Windows także host RDP bez logowania, pozycjonowanie/restart oraz testy tekstu, instalacji, aktualizacji i odinstalowania Setup.

Bramki wydania: locked restore, Release build i wszystkie testy jednostkowe na Windows/Linux, 19 scenariuszy CI UI oraz network-tools/app-polish, własne OpenSSH dla kopii/przerwań/odzyskiwania SFTP, audit advisory NuGet, manifest, opublikowany natywny host RDP bez logowania, start/pozycja/restart, teksty Setup i izolowana instalacja/upgrade/uninstall. Paczki muszą przejść zgodność ZIP/TAR/DEB, wykluczenia danych prywatnych, sumy SHA-256 i zgodność źródeł z tagiem. Ostateczne wyniki, liczniki i SHA źródeł są w `VERIFICATION.md` dołączonym do wydania; dowody lokalne w `artifacts/reports/release-0.37.0/`.

Własne testy nie używają zapisanych serwerów ani poświadczeń użytkownika. Aktywna aplikacja i wcześniejsze zamrożone paczki pozostają zachowane. Nie deklarujemy testów rzeczywistego logowania RDP, AD/Microsoft, fizycznego Serial/IME, natywnego GNOME/KDE ani monitorów o mieszanym DPI. Nie dodano zależności ani nowego schematu bazy. Szczegółowe granice poprzednich etapów: [kopie danych](database-backups-2026-10-16.md), [błędy transferów](transfer-errors-2026-10-16.md), [przerwania i `.part`](sftp-interruption-2026-10-16.md), [odzyskiwanie SFTP](sftp-browser-recovery-2026-10-16.md).
