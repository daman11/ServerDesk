# Weryfikacja ServerDesk 0.45.0

Data: 2026-10-21. Bieżące wyniki końcowych bramek są dołączane do lokalnego wydania jako `VERIFICATION.md`; przygotowanie paczek nie jest publikacją na GitHub.

Zakres: aktualizacje GitHub (stałe repozytorium, metadane, SHA-256, ograniczone pobieranie, kopia i przekazanie instalacji), regresje istniejącego MVP, Windows/Linux i paczki. Wszystkie dane i odpowiedzi HTTP w testach aktualizatora są syntetyczne. Nie wykonujemy aktualizacji instalacji maintenera ani połączeń do zapisanych serwerów.

Macierz UI: **54/54 Windows i 52/52 obsługiwane scenariusze Linux**, w tym bieżące CI, aktualizacje i nawigacja komend; Windows-only OLE/drop/export nie są liczone jako transfer Linux. DataProbe: 8/8 na każdym systemie. Kandydat Setupu przeszedł świeżą instalację, aktualizację 0.44.0 → 0.45.0, ochronę zajętych plików, naprawę i odinstalowanie z zachowaniem danych. Rejestrację systemową celowo pominięto. Końcowe paczki są przebudowywane z czystego commita i ponownie przechodzą bramki instalatora/zawartości przed zamrożeniem.

Testy jednostkowe: **Windows 1034/1034 i Linux 1034/1034**, bez pominięć. Kontrola metadanych, wersji/downgrade, przekierowań, sum i rozmiarów, przerwania pobierania, zachowania istniejącego pliku oraz argumentów ścieżek ze spacjami i Unicode. UI PL/EN sprawdza pusty GitHub, metadane nowszej wersji, przygotowanie instalatora i kopii bez uruchamiania Setupu, anulowanie zamknięcia oraz dokładnie jedno przekazanie po zatwierdzeniu. Przyciski pozostają widoczne na 430×350 px przy font16; tekst można przewinąć. Końcowe Pomoc/O programie oraz Windows/Linux UI aktualizacji powtórzono po zmianie układu. Pełne wyniki finalnych paczek opisuje raport w wydaniu.

Początkowe kompilacje wykryły literówkę w nazwanym argumencie testu i nieprawidłową przestrzeń nazw roli dekoracji Avalonia; poprawiono je, po czym celowane scenariusze przeszły. Pierwszy publish pojedynczego EXE ujawnił implicit Microsoft.NET.ILLink.Tasks: ustawienia pojedynczego pliku przeniesiono do projektu pomocnika, a lockfile zaktualizowano świadomie. Nie wyłączono locked restore. Początkowe NU1900 z izolowanej sieci nie są wynikiem audytu; osobny aktualny audyt z dostępem do NuGet zaliczył wszystkie pięć projektów i 23 przypadki bramki. Test rzeczywistego ENOSPC na osobnym tmpfs 8 MiB potwierdził zachowanie danych i udane ponowienie; nie zapełniano dysku użytkownika.

Nie potwierdzono aktualizacji z dwóch rzeczywistych opublikowanych wydań ani rejestracji instalatora na czystej VM. Repozytorium zostało utworzone puste; kod i paczki nie są wysyłane bez decyzji maintenera. Brak Authenticode i niezależnego klucza podpisującego manifest. SHA-256 z GitHub API działa w modelu zaufania HTTPS/konta GitHub. WSL/headless nie zastępują fizycznego wejścia, różnych DPI ani natywnych magazynów Linux.
