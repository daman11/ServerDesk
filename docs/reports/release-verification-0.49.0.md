## Boundaries

Email/master-password sign-in with authenticator/email/YubiKey OTP is supported. GUI SSO/FIDO2 and primary personal API-key sign-in are outside this implementation. Additional client_secret protection during email sign-in uses a masked prompt and stdin. Successful real-account login, sync/decryption and every server/MFA configuration still require a separate disposable-account acceptance test.

Secrets are absent from ServerDesk settings/logs/argv; master/session values use child environment and codes use stdin. Upstream account tokens and encrypted cache persist in the owned per-server/email profile. Dialog close forgets ServerDesk unlock; explicit owned-profile sign-out clears login. External profiles are never reconfigured/signed out. Disable and factory reset retain cache/recovery data and are not secure wipes; SQLite backup does not include account-cache directories. Same-user processes and immutable managed strings are outside guaranteed erasure/isolation.

No VMware/hardware acceptance was repeated. Existing physical RDP keyboard/mouse/IME/DPI, reverse file-transfer, monitor-off/network and clean-distribution acceptance limits remain. Packages are unsigned; no remote push/publication was performed.
